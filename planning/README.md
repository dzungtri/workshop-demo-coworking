# /planning

Thư mục này chứa kế hoạch sản phẩm và kế hoạch sprint.

## Vai trò

- `backlog.md`: danh sách việc cần làm ở cấp sản phẩm, ưu tiên bằng bảng
- `/sprints`: các file kế hoạch theo từng sprint, mỗi sprint là một file riêng

## Quy ước

- Mỗi task trong `/tasks` nên map được về một mục trong backlog hoặc sprint
- Backlog là nguồn ưu tiên cấp sản phẩm, sprint là nguồn ưu tiên thực thi ngắn hạn
- Khi ưu tiên thay đổi, cập nhật backlog trước rồi mới cập nhật sprint
