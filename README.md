# Jerry LMS

Minimal LMS project base for the Team + AI workflow.

This repository currently contains the runnable foundation only:
- Vite + React + TypeScript
- one Hello LMS landing page
- a basic test setup

Product features such as login, courses, enrollments, and my courses are not implemented yet.

## Requirements

- Node.js 22+
- npm 10+

## Setup

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```

Build the app:

```bash
npm run build
```

Run tests:

```bash
npm run test
```

Type-check only:

```bash
npm run check
```

## What you should see

Open the dev server and you should see a simple `Hello LMS` page that confirms the project base is running.
