# ADR Writing Skill

Use this when making important technical decisions.

## ADR required when deciding
- Architecture style
- Tech stack
- Database
- API style
- Service boundaries
- Folder structure
- Coding convention
- Testing strategy
- CI/CD strategy

## ADR format

# ADR-XXXX: <Title>

## Status
Proposed | Accepted | Superseded

## Context
What problem are we solving?

## Decision
What did we decide?

## Consequences
What becomes easier?
What becomes harder?

## AI/team impact
How does this help humans and agents work better?

## Rules
- Keep ADR short.
- Explain why, not only what.
- New major technical change requires new ADR.
