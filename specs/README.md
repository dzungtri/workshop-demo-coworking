# /specs

Thư mục này là nguồn sự thật cho sản phẩm và nghiệp vụ.

## Cấu trúc chuẩn

- `product-vision.md`: mục tiêu sản phẩm, bối cảnh, phạm vi, giá trị kinh doanh
- `domains.md`: miền nghiệp vụ, thực thể, quan hệ dữ liệu
- `user-roles.md`: vai trò người dùng và quyền hạn
- `features.md`: tính năng, màn hình, luồng sử dụng, tiêu chí nghiệm thu
- `api-contracts.md`: hợp đồng API, request/response, quy tắc lỗi

## Tài liệu hiện có của LMS

Repo này đang dùng bộ tài liệu LMS sau:

- `lms-rfp.md`: bản mô tả nhu cầu sản phẩm
- `lms-spec.md`: bản đặc tả chức năng
- `lms-mvp.md`: trang tương thích cho đường dẫn cũ

Khi thêm tài liệu mới, ưu tiên:

1. Viết vào file đúng ngữ cảnh trong `/specs`
2. Cập nhật link từ task và README nếu cần
3. Không để hai file mô tả cùng một quy tắc mà lại khác nhau
