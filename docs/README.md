# /docs

Thư mục này chứa tài liệu bổ sung, không phải nguồn sự thật chính.

## Nên đặt ở đây

- Runbook vận hành
- Hướng dẫn triển khai
- Sơ đồ kiến trúc
- Notes cho demo hoặc trình bày

## Không nên đặt ở đây

- Đặc tả sản phẩm chính
- Hợp đồng API chuẩn
- Quyết định kiến trúc

Những nội dung đó nên nằm ở `/specs` hoặc `/adrs`.
